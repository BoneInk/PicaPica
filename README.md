# PicaPica

PicaPica 是一款 Android 平台的 PicACG 第三方漫画客户端，使用 Kotlin 和 Jetpack Compose 开发，采用 Material Design 风格界面。

支持分类与排行榜、组合搜索、横竖阅读、离线下载、云收藏、评论互动及最近评论内展开回复，并提供关键词、标签、分类和 AI 内容屏蔽，以及主题、阅读和图片相关设置。

## 下载

在 [Releases](https://github.com/BoneInk/PicaPica/releases) 下载 APK 安装。当前版本为测试版，支持 Android 8.0 及以上。

## 构建

使用 Android Studio 打开项目，或配置 JDK 17 和 Android SDK 36 后运行：

```sh
./gradlew assembleDebug
```

PicaPica 并非 PicACG 官方应用，不内置漫画内容，使用时需要自己的 PicACG 账号。

第三方协议参考与许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
