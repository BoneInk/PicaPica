# PicaPica

PicaPica 是一款 Android 平台的多数据源第三方漫画客户端，支持 PicACG 和香香腐宅，使用 Kotlin 和 Jetpack Compose 开发。

支持分类与排行榜、组合搜索、横竖阅读、逐章阅读记忆、离线下载、云收藏、评论互动及各层楼中楼直接展开与回复，并提供关键词、标签、分类和 AI 内容屏蔽，长按作品、标签或分类可快捷屏蔽。支持在应用内注册 PicACG 和香香腐宅账号、手动每日签到，以及各数据源支持的头像和资料编辑。

## 下载

在 [Releases](https://github.com/BoneInk/PicaPica/releases) 下载 APK 安装。当前版本为测试版，支持 Android 8.0 及以上。

从 0.13.0 起，可在「我的 → 设置 → 关于 → 检查更新」查询 GitHub Releases 上的新版，在应用内下载并交由 Android 确认安装。

应用内更新读取 `vX.Y.Z` 标签和 GitHub 提供的 APK SHA-256。预览渠道使用 `PicaPica-X.Y.Z-preview.apk` 或 `PicaPica-X.Y.Z-debug.apk`，正式渠道使用正式发布中的 `PicaPica-X.Y.Z.apk` 或 `PicaPica-X.Y.Z-release.apk`。用于更新的 APK 需沿用对应渠道的包名与签名，并递增 `versionCode`。

## 构建

使用 Android Studio 打开项目，或配置 JDK 17 和 Android SDK 36 后运行：

```sh
./gradlew assembleDebug
```

PicaPica 并非上述站点的官方应用，不内置漫画内容，使用时需要对应站点的账号。

## 账号与数据源

在「我的 → 切换账号」或「设置 → 账号与数据源」切换已保存的账号。添加账号时选择 PicACG 或香香腐宅，也可保存同一数据源的多个账号。原有 PicACG 登录、下载和阅读记录会继续保留。

香香腐宅支持图片验证码登录、邮箱验证码注册、分类与标签、搜索、人气榜、收藏榜、搜索榜、云收藏、章节阅读、离线下载、评论、楼中楼及点赞。个人资料展示昵称、头像、会员身份、FU金、经验和自动签到天数，并支持头像编辑及历史留言。在线和离线阅读均处理站点的图片重排。昵称和安全资料通过网站管理；站点没有提供的个性签名、PicACG 官方评论区及组合筛选入口按数据源能力隐藏。

香香首页按网站的数据和顺序展示「每日最新」「香香汉化组」「无码专区」切换分区，以及「最多订阅」「猜你喜欢」、腐宅快报和站内作品横幅。「更多」使用对应站点分区的分页接口，作品显示最新章节；外部广告链接不会成为首页横幅。分类、榜单、签到和搜索保留原生入口。

在「设置 → 图片与网络 → 访问站点」或登录页的「选择访问站点」选择香香主站及备用站点，选择会保存在本机。站点跳转后展示实际连接的域名，验证码与登录继续使用同一域名和会话；切换站点不会复制其他域名的登录 Cookie。

两个源均可在「我的」手动签到，先读取站点状态，提交一次后再次确认。香香同时显示本月签到天数；网络中断时可刷新状态确认结果。注册验证码仅在点击「获取验证码」时发送，提交失败会保留表单，并刷新图片验证码。

每个看过的章节分别记忆最后页码，返回目录、重开应用及离线阅读时均可继续。目录区分「上次阅读」「读至第几页」和「已读」；回看较早章节不会删除其他章节的记录，跳过或仅下载的章节不会被标为已读。升级会保留旧版本已知的最后阅读位置，不推断此前未记录的章节。

在「设置 → 阅读」选择「横向翻页」并打开「双页显示」。两页各占半屏，按原图比例填满屏幕高度，可以一起缩放。横屏和竖屏均可使用，章节最后剩一页时会居中显示。

点击章节目录右侧的「正序／倒序」切换显示顺序，选择会保存在本机，PicACG 和香香腐宅均支持。倒序时较新的章节显示在前面，继续阅读及阅读器的上一章、下一章仍按章节本身的顺序运行。

竖向连续阅读接近章节末尾时会准备下一章，图片直接拼接，向上滚动仍可回看已经加载的章节。读到下一章才会更新当前章节和阅读进度。可在「设置 → 阅读 → 竖向自动加载下一章」关闭，改为手动翻章；离线时只会接上已下载的章节。

云收藏读取站点的完整收藏列表，以作品编号关联详情和收藏状态，支持分页；收藏变更、从详情返回以及应用回到前台时会刷新列表。个人资料也会在回到前台时更新，支持手动刷新。

香香收藏接口存在 `code=0`、`msg=ok`、`succ=false` 同时返回有效收藏列表的情况，客户端会校验实际列表及分页字段，避免把正常响应显示为「ok」错误。添加或取消收藏后会回读作品状态确认结果；响应中断时只查询状态，不自动重发收藏操作。

每个账号独立加密保存登录会话，不保存密码。香香腐宅会跟随已核实站点的 HTTPS 跳转，并固定验证码、登录和后续请求使用的域名与会话。本地书库、阅读记录和内容屏蔽规则按数据源隔离；下载任务保留发起账号，切换账号后仍可继续下载。香香腐宅当前地址依据其[公告页](https://trello.com/b/V9TEaHIa)核对，站点访问和会员内容受自身规则限制。

## 验证

`./scripts/build.sh` 构建、运行单元测试及 Lint。`SourceAccountsTest` 在模拟器中验证数据源切换、独立会话、阅读、评论、下载归属、图片还原与重启恢复；`XiangxiangProtocolTest` 覆盖真实资料和收藏响应格式、留言上下文及头像上传协议。`XiangxiangLiveTest` 为需显式启用的公开只读接口检查。`XiangxiangAccountLiveTest` 通过临时会话桥验证真实账号资料、收藏和历史留言，默认联动专用模拟器的 `XiangxiangParityLiveTest` 验证原生页面与收藏添加、取消，结束时恢复原收藏集合；设置 `PICAPICA_LIVE_NATIVE=0` 可仅运行只读客户端检查。所有在线检查均不在代码中保存密码或会话，不发表真实评论或修改头像。

`ReadingProgressTest` 验证逐章恢复、阅读状态、来源隔离与重启保留；`MetadataMigrationTest` 验证数据库 v1/v2 升级到 v3 时保留原数据。`SourceFeaturesProtocolTest` 与 `SourceFeaturesTest` 覆盖两源签到、香香注册、首页分区、分页和站点选择。`XiangxiangHomeAndCheckInLiveTest` 使用临时会话验证真实首页、签到状态和站点切换，不创建真实账号或发送验证邮件；注册提交通过本地协议和原生界面测试验证。
